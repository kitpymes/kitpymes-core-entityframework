# v.2.0.1
Corrección de seguridad: Microsoft.EntityFrameworkCore.SqlServer 8.0.1 traía paquetes con vulnerabilidades conocidas, que heredaba quien instalaba EntityFramework.
- Alta: Microsoft.Data.SqlClient 5.1.1 (GHSA-98g6-xh36-x2p7) y Azure.Identity 1.7.0 (GHSA-5mfx-4wcx-rv27). Se fijan Microsoft.Data.SqlClient 5.2.2 y Azure.Identity 1.18.0.
- Moderada: Azure.Identity (GHSA-wvxc-855f-jvrv, GHSA-m5vv-6r4h-3vj9), System.IdentityModel.Tokens.Jwt y Microsoft.IdentityModel.JsonWebTokens 6.24.0 (GHSA-59j7-ghrg-fj52).
- Sin cambios en la API pública ni en el comportamiento de la librería. Quien fijara Microsoft.Data.SqlClient por debajo de 5.2.2 en su proyecto verá un error de restauración (NU1605) y tiene que subirlo.

# v.2.0.0
Versión mayor: rompe a quien venga de la 1.1.4 (la última publicada en NuGet, .NET 5). Abajo, qué cambia y cómo migrar.

- Requiere .NET 10 o superior.
- Usa las librerías Kitpymes ya migradas desde NuGet (Shared 2.0.1, Entities 2.0.0, Repositories 2.0.1); quien la use debe migrar también esas (ver sus release notes).
- El código pasa a github.com/kitpymes/kitpymes-core-entityframework y el paquete se publica desde GitHub Actions.

## Cambios incompatibles y cómo migrar desde 1.1.4

1. Métodos del repositorio con otro nombre (igual que en Repositories 2.0.0)
   - GetOne / GetOneAsync -> Get / GetAsync, que devuelven null si no hay resultado.
   - Nuevos GetByKey / GetByKeyAsync para buscar por clave.

2. Clases con otro nombre
   - DependencyInjection -> EntityFrameworkDependencyInjection.
   - OptimizedContextExtensions -> OptimizedDbContextExtensions.

3. Entities 2.0.0 cambió sus espacios de nombres y las interfaces de auditoría; las entidades de quien use esta librería deben migrarse según sus release notes.
